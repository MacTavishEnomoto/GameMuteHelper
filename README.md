# GameMuteHelper v3.0 (纯 C# 现代简约版)

使用纯 C# (.NET Framework 4.x) 完全重写的轻量后台静音与 RTSS 限帧助手，采用现代极简暗黑卡片式界面，启动更快、内存占用更低，且零外部依赖。

## 一键编译与运行（无需安装任何软件）

1. 将压缩包解压到 `D:\GameMuteHelper`。
2. 双击 **`Build_EXE.bat`**（自动调用 Windows 系统自带的 `csc.exe`，约 1 秒离线生成原生 `GameMuteHelper.exe` 并自动启动）。
3. 之后直接双击 **`GameMuteHelper.exe`** 运行即可。

## 主要升级亮点

- **现代简约卡片式 UI**：彻底告别传统表格，改用圆角应用卡片、iOS/Win11 风格滑动开关、状态胶囊徽章、分段标签页（`已接管` / `运行中`）、实时搜索与 Windows 11 原生暗黑圆角标题栏。
- **即改即生效**：开启/关闭静音、调整限帧或添加应用均自动即时保存生效，无需反复点击保存按钮。
- **纯 C# 高性能内核**：毫秒级启动、极低内存占用；修复 COM/进程句柄泄漏；自动探测 RTSS 路径并动态加载；支持失焦防抖（默认 500ms）、单实例唤醒、暂停/关机自动恢复与暗黑托盘菜单。
